# 3 Кубика

Браузерная игра в одном файле `index.html`. Работает на компьютере и на телефоне. Своего сервера у игры нет.

## Режимы
- **Игра с дилером.** Одиночный режим, работает и без интернета.
- **Онлайн до 4 игроков.** Тот, кто создаёт комнату, становится хостом: кубики бросаются на его устройстве, остальные подключаются к нему напрямую (P2P, WebRTC) по 5-значному коду. Есть общий чат и синхронные раунды. После первого «Готов» у остальных есть 25 секунд.

## Как это работает без сервера
- Игровые данные (ставки, броски, чат) идут напрямую между устройствами.
- Чтобы устройства нашли друг друга, нужно первое «рукопожатие». Его делает бесплатный публичный брокер PeerJS (`0.peerjs.com`), после этого он в игре не участвует. Поэтому для онлайна нужен интернет.
- Если прямое соединение не устанавливается (некоторые мобильные операторы), трафик пойдёт через бесплатный TURN-ретранслятор PeerJS.

## Как раздать игру
Файл `index.html` нужно доставить на каждое устройство:
- **Компьютер:** открыть `index.html` двойным кликом.
- **Android:** отправить файл себе (Telegram, почта) и открыть его в Chrome.
- **iPhone:** открыть локальный HTML-файл в Safari неудобно. Проще выложить файл на бесплатный статический хостинг (GitHub Pages, Netlify Drop): это не сервер, а просто место, откуда скачивается файл. Тогда ссылка с `?room=КОД` сразу открывает вход в комнату.

## Важно знать
- Баланс, имя и серия бонусов хранятся в браузере устройства (localStorage). Если очистить данные сайта, профиль начнётся заново.
- Хост должен держать вкладку открытой и экран включённым (игра просит не гасить экран). Если хост вышел, комната закрывается.
- В онлайне хост доверяет балансу, который сообщает гость. От читеров это не защищает: игра рассчитана на друзей.
